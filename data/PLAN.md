# Synthetic company corpus plan

User-authorized scope: research company internal financials, create a comprehensive fictional history, then expand through 100+ Luna agent runs. General agent product; crypto infrastructure company used as demonstration.

1. Research primary sources and distinguish researched principles from simulation assumptions.
2. Generate a deterministic eighteen-month financial backbone and checked AP fixtures.
3. Generate 102 separately logged Luna narrative shards against immutable source packets, bounded concurrency.
4. Validate financial invariants, source references, shard counts, and output structure; quarantine failed output.
5. Document reproducibility, provenance, usage, limitations, and safe agent-visible export.

No live counterparties, transactions, provisioning, or automatic publishing. Generator truth and narrative job inputs are developer-only. Directory separation alone is not a security boundary; production must mount only explicit agent-visible exports.

Execution update: user explicitly requested a Python/Node pool of `codex exec` processes, each with its own workspace and logs. Two initial agent-tool workers were interrupted; their research draft was retained. All subsequent generation uses CLI subprocesses, model `gpt-5.6-luna`, default concurrency 8, 102 narrative jobs.
